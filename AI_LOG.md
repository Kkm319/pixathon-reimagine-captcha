# AI Usage Log

## Project
**HUMAN.exe — CAPTCHA Arcade**

## Purpose of AI assistance
AI assistance was used to help document and explain the project, review its high-level structure, and prepare repository documentation.

## Areas supported
- Explained the role of `index.html` as the main page.
- Documented the embedded mini-games (`glitch`, `rhythm`, and `doodle`) and how the selected game is loaded in an iframe using `srcdoc`.
- Helped describe the project’s current scope and limitations in the README.
- Explained deployment options for hosting the static HTML page with GitHub Pages.

## Human review and responsibility
AI-generated explanations and documentation should be checked against the actual source code. The project owner remains responsible for reviewing, testing, and understanding the implementation before submission or deployment.

## Limitations noted
- The project is a browser-side prototype; its client-side game logic is not sufficient on its own for secure, server-verified CAPTCHA protection.
- The three games should be tested in a browser before claiming that all interactions work as intended.

## Transparency note
This log records the AI assistance described above. It does not claim that AI generated the entire application or that comprehensive browser/security testing has been completed.
