# Pixathon — Reimagine CAPTCHA

A browser-based, playful CAPTCHA concept for Pixathon.

## Run
Open `index.html` in a browser, or enable GitHub Pages for the repository and open the repository site.

## Challenge types
- **Doodle-to-Target** — draw a continuous path from a key to a lock.
- **Catch the Glitch** — select the different symbol.
- **Rhythm Micro-Jitter** — tap four times with consistent timing.

The root page is the canonical app and uses `style.css` and `app.js`. `arcade/index.html` redirects to it to avoid leaving a nonfunctional duplicate launcher.

## Limitations
This is a class/demo concept, not production-grade CAPTCHA or security software. The mini-games are playful client-side interactions and cannot reliably distinguish humans from automated scripts.
