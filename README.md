# Pixathon — Reimagine CAPTCHA

A browser-based, playful CAPTCHA concept for Pixathon.

## Problem-statement requirements
- Runs in the browser.
- At least three challenge types or a random challenge generator.
- Clear pass/fail feedback.
- Challenges designed to take under 30 seconds.
- Restart without page reload.
- Concept demo only, not production security software.

## Current prototype
Randomly selects Doodle-to-Target, Catch the Glitch, or Rhythm Micro-Jitter. Includes a shared verification screen, 25-second timer, result message, and retry flow. Built with plain HTML, CSS, and JavaScript.

## Run
Open `index.html` in a browser or enable GitHub Pages for the repository.

## Team integration
Each game owner should provide game HTML/CSS/JS, assets/audio, run instructions, and a clear way to report success/failure and reset without a page reload. Coordinate before replacing shared files.

## Limitation
This is a playable concept for demonstration; it does not reliably distinguish humans from bots or provide production-grade security.
