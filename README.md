# Pixathon — HUMAN.exe CAPTCHA Arcade 🤖

A playful, interactive browser-based verification arcade built for the Pixathon Hackathon. Features three gamified verification challenges designed to reimagine traditional CAPTCHAs into enjoyable, human-centric interactions.

---

## 🎮 Mini-Game Challenges

| Challenge | Verification Mechanism | Description |
|-----------|------------------------|-------------|
| **Catch the Glitch** | Visual Observation | Six animated toy creatures appear on screen; five follow the pattern, while one exhibits anomalous behaviour. Identify the glitch before the timer runs out! |
| **Rhythm Tap** | Audio-Visual Timing | Follow the auditory and visual tempo prompts to verify authentic human reaction cadence and micro-timings. |
| **Doodle-to-Target** | Fine Motor Dynamics | Connect or trace targets on the canvas to prove human cursor dynamics and smooth motor control. |

---

## 🚀 Quick Start

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Kkm319/pixathon-reimagine-captcha.git
   cd pixathon-reimagine-captcha
   ```
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge):
   - No build step, package manager, or local web server required.
   - All styles, vector creature assets, and synthesised Web Audio logic are self-contained.

---

## ✨ Key Features

- **Zero-Dependency Architecture:** Entire arcade is bundled into a single standalone HTML file.
- **Synthesised Web Audio:** Uses the Web Audio API for background music and interactive sound effects without external audio files.
- **Adaptive SVG Animations:** Inline vector illustrations and CSS keyframe animations for high performance across all screen resolutions.
- **Interactive Feedback:** Visual confetti celebrations, streak tracking, countdown rings, and witty verification feedback states.
